# Simple Calculator

## Overview

This project is a Python-based command-line calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User Input Handling
- Match-Case Statements
- Exception Handling

## Technologies Used

- Python

## Test Case

First Number: 100

Second Number: 50
